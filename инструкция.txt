1. Зашли на гитхаб в свой проифль
2. Перешли на вкладку репозитории
3. нжимаем new - создать новый репозиторий
4. Даем название репозиторию 
5. Настраиваем конфигурацию



Команды
git add . - сохраняет измения 
git status - проверть статус репозитория (что всё добавлено)
git commit -m "название комита" - зафиксировать изменения  
git push origin main - отправили изменения на гитхаб в репозиторий


git clone "ссылка на репозиторий" - клонировть репозиторий
